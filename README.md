# 📱 База данных студентов

## Описание
Приложение для управления информацией о студентах института на Android.

## 🔧 Технологии
- Java
- Android SDK (API 24+)
- Room Database
- RecyclerView, ViewPager2, Material Design

## ✨ Функционал
- ✅ Управление группами (добавление, редактирование, удаление)
- ✅ Управление студентами (ФИО, дата рождения, группа)
- ✅ Переключение между списком групп и студентов (вкладки)
- ✅ Сортировка студентов:
  - По фамилии (А-Я / Я-А)
  - По группе (возрастание / убывание)
- ✅ Защита от удаления группы со студентами
- ✅ Проверка на дубликаты (уникальный номер группы, уникальное ФИО студента)

## 📥 Установка
1. Скачайте [project.apk]
2. Разрешите установку из неизвестных источников в настройках телефона
3. Запустите файл и следуйте инструкциям
